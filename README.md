# StyleHub – Fashion and Clothing Website

## Objective
A simple fashion website to display clothing products and prices.

## Features
- Three clothing products
- Responsive layout
- Add to Cart buttons with a live cart counter

## Technologies
- HTML
- CSS
- Basic JavaScript (only for the cart counter)

## Setup
Open `index.html` in any web browser.

## Deployment
Upload this project to GitHub and deploy it on Vercel. Add your live website URL here.
