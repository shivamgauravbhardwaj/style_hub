# StyleHub – Fashion and Clothing Website

## Objective
A beginner-friendly fashion store website that displays clothing products and lets users browse a small collection.

## Features
- Six product cards with prices and labels
- Search products by name
- Filter by category
- Sort by price or name
- Add-to-cart counter
- Add-to-cart confirmation message
- Responsive layout for mobile and desktop

## Technologies Used
- HTML
- CSS
- Basic JavaScript for search, filters, sorting, and cart counter

## Run Locally
1. Download and extract the ZIP file.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.

## Deployment
Upload the files to a GitHub repository and import that repository into Vercel. Add your deployed URL here after publishing.
